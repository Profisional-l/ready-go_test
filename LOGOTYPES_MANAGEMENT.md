# 📋 Управление логотипами компаний

## Что было создано:

### 1. **Файлы данных и конфигурация**
- `src/data/clients.json` - JSON файл со всеми логотипами компаний в нужном порядке
- Там хранятся все 9 существующих логотипов (CocaCola, KFC, MTBank, ARARAT, Nivea, BonAqua, Sportmaster, Aps, Glenlivent)

### 2. **Админ панель**
- **Новый раздел в админке:** `/admin/clients` 
- **Функционал:**
  - ➕ Добавление новых логотипов из списка доступных SVG файлов
  - 🗑️ Удаление логотипов
  - ⬆️⬇️ Изменение порядка логотипов
  - 💾 Сохранение новых порядков

### 3. **API**
- Новый endpoint: `GET /api/clients` 
- Возвращает список логотипов отсортированные по порядку

### 4. **Компоненты**
- `ClientsSection.tsx` - обновлен для загрузки логотипов из JSON через API
- `AdminClientsContent.tsx` - интерфейс управления логотипами
- `AdminNav.tsx` - навигация между Кейсами и Логотипами

---

## 🎮 Как использовать:

### В админ панели:
1. Перейди в "Панель администратора" → вкладка "Логотипы компаний"
2. **Для добавления логотипа:**
   - Введи название компании
   - Выбери логотип из выпадающего списка
   - Нажми "Добавить"
3. **Для изменения порядка:**
   - Используй кнопки ⬆️ и ⬇️ в таблице
   - Нажми "Сохранить порядок"
4. **Для удаления:**
   - Нажми 🗑️ и подтверди удаление

### На сайте:
- На секции "Логотипы" (About/Clients) автоматически отобразятся логотипы в нужном порядке из JSON файла

## 🔧 Серверные функции (actions.ts):

- `getClients()` - получить список всех логотипов
- `addClientAction()` - добавить новый логотип
- `deleteClientAction()` - удалить логотип
- `updateClientsOrderAction()` - сохранить новый порядок
